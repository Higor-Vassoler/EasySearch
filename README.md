# EasySearch
A personal project designed to make searching for OP.GG profiles easier. Simply enter a player's username in the search bar, and EasySearch will find all available OP.GG profile links for that player.

## How to run:
1. Clone or download the repository.
2. Create a `.env` file in the backend's directory and provide the required URL and PORT variables.
3. Open a terminal in the project's root directory.
4. Run the command `npm run install:all` to install the dependencies for the root, backend, and frontend.
5. Run the command `npm run dev` to start both the frontend and backend simultaneously.
